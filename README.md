# ゲーム棚

自作のブラウザゲームを並べるサイトです。`index.html` がトップページで、このリポジトリにあるゲームのHTMLを自動で見つけて並べます。

---

## ゲームを追加するとき

1. ゲームのHTMLファイルをこのリポジトリにアップロードする（GitHubの「Add file → Upload files」）
2. おわり。トップページに自動で並びます

ファイル名は自由です（英数字がおすすめ）。`game_20261001_xxx.html` のように日付を入れておくと、ラベルに追加日が無いときの代わりに使われます。

---

## ゲームに「ラベル」をつける（おすすめ）

トップページでは、ゲームを **人数** と **タグ** でさがせます。
これは、ゲームのHTMLの `<head>` の中に書いた「ラベル」を読んで表示しています。

```html
<!-- ゲーム棚のラベル（index.html が読みます） -->
<meta name="game:players" content="3-8">
<meta name="game:tags" content="ブラフ,読み合い">
<meta name="game:date" content="2026-10-01">
```

| ラベル | 書き方 | 意味 |
|---|---|---|
| `game:players` | `3-8`、2人専用なら `2` | 遊べる人数 |
| `game:tags` | `ブラフ,読み合い`（カンマ区切り、2〜3個） | さがすときのタグ |
| `game:date` | `2026-10-01` | 棚に追加した日（新着順と「NEW」に使う） |
| `game:time` | `10-15`（書かなくてもOK） | だいたいのプレイ時間（分） |
| `game:color` | `#56A8FF`（書かなくてもOK） | カードの色を指定したいとき |
| `game:hidden` | `true`（書かなくてもOK） | 作りかけなどで、棚に出したくないとき |

あわせて、`<title>`（ゲーム名）と `<meta name="description" content="…">`（ひとこと説明）も書いておくとカードに表示されます。

### ラベルを書き忘れても大丈夫

ラベルが無いゲームも、ちゃんと棚に並びます。

- **人数**：ゲームの中の「3〜8人」などの文から推測します
- **タグ**：説明文の言葉から推測します（「ウソ」→ #ブラフ など。対応表は `index.html` の `autoTags`）
- **追加日**：ファイル名の日付（`20261001` など）を使います

推測はあくまで「代わり」なので、きちんと書いたほうが正確です。

---

## タグのルール（増えても迷わないために）

ゲームが増えるとジャンル分けが難しくなるので、「ジャンル1つに決める」のではなく **タグを2〜3個つける** 方式にしています。1本のゲームが「ブラフ」でも「対戦」でもある、という状態をそのまま表せます。

**なるべく今あるタグから選んでください。** 似たタグが増えると、さがしにくくなります。

| タグ | どんなゲーム？ |
|---|---|
| 協力 | みんなで力を合わせてクリアをめざす |
| 対戦 | 勝ち負けがはっきりある |
| ブラフ | ウソ・はったりで相手をだます |
| 読み合い | 相手が何を出すか・どう動くかを読む |
| 推理 | 手がかりから答えや犯人を当てる |
| ことば | 言葉やヒントを考えて伝える |
| 以心伝心 | 相手と同じ答えをそろえる |
| お絵かき | 絵をかく |
| 演技 | 声や表情で演じる |
| 大喜利 | おもしろい答えを考える |
| 正体隠し | 誰か1人だけ違う（ワードウルフ・人狼っぽいもの） |
| 早押し | 反射神経・スピード勝負 |
| ボード | 盤の上でコマや石を動かす |

新しいタグを作ってもOKです。トップページのタグは「使われている数が多い順」に並び、多すぎるときは上位8個だけ出して残りは「ほか◯個」にたたまれます。

## Claudeにゲームを作ってもらうときの一言（コピペ用）

新しいゲームを作ってもらうとき、最後にこれを貼っておくと、最初からラベル付きのHTMLができます。

```
完成したHTMLの <head> に、ゲーム棚用のラベルを入れてください。
・<title> にゲーム名、<meta name="description"> に40字くらいのひとこと説明
・<meta name="game:players" content="最小-最大">（例：3-8。2人専用なら 2）
・<meta name="game:tags" content="タグ,タグ">（2〜3個。次の中からなるべく選ぶ：
  協力, 対戦, ブラフ, 読み合い, 推理, ことば, 以心伝心, お絵かき, 演技, 大喜利, 正体隠し, 早押し, ボード）
・<meta name="game:date" content="今日の日付 YYYY-MM-DD">
```

## 棚卸しページ（管理用）

トップページのURLの最後に `?kanri` を付けて開くと（例：`https://〜/index.html?kanri`）、管理用の一覧が出ます。

- 全ゲームの 追加日・人数・タグ・ファイル名 の表
- ラベルが無くて「自動（推測）」で埋めた項目に印がつく
- 説明文が無いゲーム、非表示にしているゲーム
- タグごとの本数（1本だけのタグは赤いふち → 似たタグにまとめられないかの目安）

ゲームが増えてきたら、ときどきここを見て整えるのがおすすめです。

## そのほか

- **棚に出したくないファイル**：ファイル名を `_` で始めるか、`game:hidden` を `true` にする
- **カードに画像を使いたい**：ゲームと同じ名前の画像（例：`game_20261001_xxx.png`）を置くと、カードの絵になります
- **サイトの設定**：`index.html` の中の「ここだけ書きかえればOK」の部分
  - `newDays` / `newMax`：「NEW」を何日間・何本までつけるか
  - `autoTags`：ラベルが無いときに、説明文のどの言葉からどのタグを推測するか
- **今日遊ぶゲームをランダムに決めたい**：「ルーレットで決める」は、いま絞り込んでいる条件（人数・タグ・さがす言葉）の中から1本選びます
