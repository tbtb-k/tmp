遊び方

  1. 全員に同じセリフと、A〜Fの6つの場面が配られます。自分がどの場面を演じるかは、自分のスマホにだけこっそり出ます。
  2. 順番が来たら、そのセリフを声と表情だけで演じます。手や体は使っちゃダメ。セリフ以外の言葉もなし！
  3. ほかの人は、どの場面の演技だったかをスマホで投票。演じた人が「演じた！」を押すと、投票は20秒で締め切り。
  4. 当てた人は1点。演じた人は当ててくれた人数ぶんの点。全員正解ならボーナス1点。これを全員分くり返して、1〜3幕で一番点が多い人の勝ち！
EXAMPLE
「うそでしょ」
A 最後のから揚げを取られた
B サプライズで誕生日を祝われた
C 体重計に乗った …
同じ「うそでしょ」でも、絶望・歓喜・現実逃避で全然ちがう！

🍻 コツ：演技はちょっと大げさなくらいがちょうどいい。同じ場面を2人が引くこともあります。
